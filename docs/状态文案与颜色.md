# 状态文案与颜色

截至 0.2.3。下表对应左下角状态栏；默认文字色会随白色/暗黑外观切换。状态详情标题采用同样颜色，没有彩色状态圆点。

| 状态 | 中文文案 | 字体颜色 |
| --- | --- | --- |
| disconnected | 等待 iPhone | 默认文字色 |
| discovering | 发现设备 | 默认文字色 |
| trust_and_developer_mode | 检查信任与开发者模式 | 默认文字色 |
| checking_image | 检查开发组件 | 默认文字色 |
| preparing_image | 准备开发组件 | 默认文字色 |
| mounting_image | 加载开发组件 | 默认文字色 |
| opening_tunnel | 建立连接 | 默认文字色 |
| opening_location_service | 连接定位服务 | 默认文字色 |
| recovering | 清理上次会话 | 默认文字色 |
| ready | 手机已连接 | 绿色 |
| simulating | 定位修改已发送 | 应用主色调（青绿色） |
| stopping | 正在停止 | 默认文字色 |
| retrying | 连接暂不可用，正在重试 | 黄色 |
| recovery_required，未附具体错误 | 定位状态待确认，请在手机地图核对位置。 | 红色 |
| 未识别阶段的兜底 | 正在处理 | 默认文字色 |

具体错误优先于阶段文案及颜色：只要当前存在错误，就显示完整错误原因并使用红色。例如连接中断时通常显示「连接已中断，手机定位状态待确认」，未收到后台具体文案时兜底为「连接已断开，请在手机确认位置状态。」；后台退出显示「后台已退出。若此前正在模拟，请在手机确认位置状态。」；请求失败、连接准备失败、输入校验失败及诊断导出失败显示各自的具体错误文字。因此「连接暂不可用，正在重试」等阶段若同时存在错误，看到的是红色错误详情。

「定位修改已发送」表示设备定位服务接受请求，不表示已经在手机地图确认蓝点更新。设置、搜索、坐标识别和收藏自身的局部提示仍在对应操作附近，不属于此手机状态表。
