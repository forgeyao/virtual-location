# 使用与验证

当前交付为原生界面与后台已集成的本机开发版。固定位置设置与恢复已在特定设备上验证，不能推广为全部设备或地区的兼容承诺。桌面普通模式自动准备设备，必要时会向 Apple 发送硬件标识和 nonce，且没有单独授权弹窗；命令行则通过显式参数允许签名。请先阅读根目录 README 的隐私说明，或使用不访问设备的预览模式。

## 环境

当前基线为 Apple Silicon Mac，Python 3.14，pymobiledevice3 11.49.0。依赖固定在 `uv.lock`，不使用系统全局 pip。

```sh
cd virtual-location
sh scripts/setup.sh
```

安装需要网络，仅将依赖放入项目 `.venv/`。之后可直接运行 `scripts/device.sh`，不在每次启动时更新依赖。

## 不设置位置的检查

```sh
sh scripts/device.sh doctor
```

仅枚举 USB 设备，输出不含完整 UDID。`Network` 设备不作为候选。此命令不发送签名请求，也不改变定位。

## 实机验证

手机应解锁、信任电脑、开启开发者模式，并退出其他定位工具。

```sh
# 连接开发服务，但不设置位置。必要时申请 Apple 签名并挂载镜像。
sh scripts/device.sh --allow-apple-signing prepare

# 明确设置 WGS84 坐标，保持 10 秒后发送清除请求。
sh scripts/device.sh --allow-apple-signing test-location --seconds 10 -- -33.8568 151.2153

# 重连并发送清除请求。
sh scripts/device.sh --allow-apple-signing clear
```

若已挂载合适镜像，准备过程会跳过签名。缺少镜像时，不传 `--allow-apple-signing` 会返回 `APPLE_SIGNING_CONSENT_REQUIRED`。开发镜像在 `.state/ddi/` 独立缓存，不改动旧全局目录。缓存保存 SHA256 校验记录，并检查开发镜像构建号；最终有效性由手机校验 Apple 签名。

`set` 调用成功仅表示指令已发送，`clear_sent` 也不代表已确认恢复。必须在手机地图观察位置和恢复情况。关闭进程、拔线或系统睡眠可能来不及清除，后续重连会优先处理未完成的清理，不自动应用旧位置。

## JSON 后台接口

```sh
sh scripts/device.sh serve
```

使用 stdin/stdout 单行 JSON。每条请求必须有唯一的 `requestId`。日志默认不输出第三方原始错误，以避免设备标识等信息泄露。

```json
{"requestId":"1","command":"discover"}
{"requestId":"2","command":"prepare","deviceId":"使用 discover 返回的 id"}
{"requestId":"3","command":"setLocation","sessionId":"使用 prepare 返回的 sessionId","latitude":-33.8568,"longitude":151.2153}
{"requestId":"4","command":"clear"}
{"requestId":"5","command":"disconnect"}
```

按请求响应顺序提交，准备完成前不能设置位置。支持 `diagnostics` 与 `cancel`；`clear`、`disconnect` 和 `cancel` 可打断当前操作。准备被取消后可能需要重连再清除。每两秒检查 USB 和 lockdown 连接，断开时显示状态待确认。该检查不能代替手机侧的定位结果验证。

同一状态目录只允许一个后台会话。退出或 stdin EOF 会尽力清理；强制终止和断线无法保证清理成功。

## 离线测试

```sh
.venv/bin/python -m pytest -q
```

测试通过假设备适配器和模拟网络响应验证状态与异常处理，不连接手机，不申请 Apple 签名。实际手机上的持续保持、锁屏、重连及速度指标仍需后续验证。

## 原生应用

```sh
sh scripts/build-app.sh
open dist/虚拟定位.app
```

应用位于项目 `dist/虚拟定位.app`，保留项目目录与 `.venv/`。这是依赖项目运行环境的本机开发版，移动项目后请重新构建。构建使用 SwiftPM native 引擎适配当前 Command Line Tools；该选项在 Swift 6.4 中有弃用提示，未来工具链升级时需要重新评估。

更新后需要在应用菜单选择「退出虚拟定位」（或 ⌘Q），再打开上述应用包；关闭窗口只会隐藏主窗口，旧进程仍然运行。当前版本为 0.2.3，可在「关于虚拟定位」核对。

界面流程：插入并解锁 iPhone，等待自动连接 → 搜索、地图选点或输入经纬度 → 修改定位 → 还原定位 → 手机确认恢复。启动时已有手机接入也会自动连接。多台设备按稳定顺序选第一台，已有连接不会切换。输入时显示 Apple 地点联想，可选择建议或按回车搜索；地图网络不可用时仍可直接输入坐标。坐标一致性已在公开地标的特定设备环境中验证，其他地区仍需逐项验收。

手机状态与全局操作错误统一位于左下角，不再显示彩色圆点，也不在收藏下方重复显示。准备完成显示绿色「手机已连接」，定位服务接受设置请求后显示应用主色调（青绿色）「定位修改已发送」；此状态不等于已在手机地图确认位置。等待设备、准备/连接及正常还原等状态为普通文字，重试状态为黄色；连接中断、后台退出、操作失败与定位状态待确认为红色完整提示，长内容换行。异常提示优先于正常状态的颜色。点击信息图标可查看处理说明，连接诊断仍在设置里。

设置中的「坐标系」区分 GCJ-02（国内地图）与 WGS84（GPS），默认 GCJ-02，保存后下次启动沿用。该默认值用于手工输入经纬度；地图选点、搜索和已保存收藏保留各自的坐标系，不因输入默认值改变而被重新解释。输入 GPS 坐标时应先在设置选择 WGS84。地图选点和搜索会自动确认坐标系，显示值保持地图原值，发送手机前适配成 WGS84。无法确认地图坐标系时，修改定位暂不可用，可重新选点或在设置中明确确认当前数值的坐标系；旧版国内收藏确认后保存标记，不静默改变原坐标。转换只用于已确认的坐标来源，不作全地区精度承诺。

选点使用长尖端的青绿色水滴形图钉，白色描边和中心圆提升深浅底图上的对比度，尖端准确锚定坐标。缩放、旋转或倾斜地图后仍以同一个尖端落点定位，不因外观改变而偏移。

「修改定位」上方增加「随机偏移」开关，首次启动默认关闭。开关和范围会保存到本地，下次启动时恢复。开启后可选择 50、100、150、200 米（首次选中 50 米）：数值是以原选点为中心、南北与东西对齐的正方形边长。例如 50 米表示 50×50 米，两个方向各为 −25 至 +25 米；200 米表示 200×200 米，两个方向各为 −100 至 +100 米。每次点击「修改定位」独立随机取点；切换开关、调整范围或等待均不会自动发送。关闭后仍发送原选点。

随机偏移先将所选坐标适配为 WGS84，再按地面米数计算并发送，保留原输入、图钉、收藏和地图视野，不累计偏移。采用球面短距离计算，在当前最大范围内与椭球距离差小于 1 米；这不是手机定位精度承诺。发送成功后界面展示「上次随机发送（WGS84）」的数值，含义是后台请求成功，不等于手机端已验证。该新功能已完成模拟后端、范围分布、极区/跨日期变更线及界面验证，本轮未做实机验收。


桌面版没有手动连接面板或签名开关，自动准备时允许必要的 Apple 签名，已有合适开发镜像时跳过申请。此行为在 README 中公开说明，本机开发期间的授权不代表其他使用者已授权。拔线后等待设备重新出现，重连会先清理上次会话，不自动应用旧坐标。普通连接失败会稍后重试；签名、挂载、恢复清理失败或用户取消时，需要重新插入手机才再尝试，避免循环执行这些操作。界面关闭后仍可通过菜单栏重新显示或停止；退出应用会先取消任务、尽力清除并释放后台。清除请求成功不代表已在手机验证恢复。

### 显式界面预览

```sh
open dist/虚拟定位.app --args --preview
```

预览模式显示橙色标记，使用模拟设备，无 USB 读写或 Apple 签名。它仍可显示在线地图，不能视为完全离线地图。自动检查模式也可仅对模拟设备运行：

```sh
dist/虚拟定位.app/Contents/MacOS/VirtualLocation --preview --ui-smoke
```

该命令自动检查连接、设置、清除、断开、退出并输出 JSON。不是实机验收。界面截图通过应用自身视图缓存生成，未验证 Metal 地图图层的截图完整性。

上次选点的经纬度、名称、坐标系和地图落点会自动保存到本地，下次启动后恢复。手工输入会保留最后一组有效坐标；无效的输入不会覆盖已有的有效选点。旧设置中的 30 米随机范围会使用 50 米，偏移开关继续沿用上次状态。

## 地图、收藏与诊断

地图铺满右侧区域，地址搜索浮在地图中间靠上的位置，以提亮底色、青绿色边框和阴影突出显示。文字非空时右侧显示清除按钮；清除会取消正在进行的联想与搜索，避免旧结果重新出现。输入短暂停顿后通过 Apple MapKit 获取联想，选中后解析地点并更新目标坐标，仍需手动修改定位。搜索结果就近展开，Esc 可收起结果并保留文字。「回到选点」位于地图左上角，也支持查看手动输入的有效经纬度。状态固定在整个窗口左下角，不随侧栏滚动，点击可查看详细说明，处理期间仍可取消。窗口标题文字与侧栏品牌区已移除，「关于虚拟定位」明确使用应用 logo。

选好位置或输入有效经纬度后，点击「坐标」右侧的星标，填写名称并收藏，最多保存 5 个。「收藏」位于坐标下方，按最新到最老排列；满额再收藏会询问是否覆盖最老的一项，可以覆盖或取消。提示框使用原生 macOS 控件，覆盖为系统蓝色默认按钮（Return），取消为普通按钮（Escape），避免红色叠色。旧版收藏自动兼容并转为相同顺序，不会在每次启动时反复倒序。点击收藏名称会选用该位置，仍需点击「修改定位」才会发送至手机。收藏行右侧「···」提供修改名称与删除；改名保留坐标、顺序和标识。实心星标仍可取消当前收藏。收藏保存在项目 `.state/favorites.json`，下次启动自动读取；预览使用独立文件，不影响真实收藏。收藏的位置不会加入诊断日志或发送到 Apple 签名服务。

「连接诊断」已移至设置窗口，默认收起；展开后显示实时诊断记录，文字左对齐，导出按钮位于内容右下角，记录较长时可滚动查看。

## 外观与语言设置

点击左下角齿轮，或应用菜单「设置…」（⌘,）打开设置。中英文的标题、说明和诊断内容均左对齐。外观提供「跟随系统」（默认）、「白色」、「暗黑」，由 AppKit 统一管理；语言提供中文（默认）和 English。更改立即应用于主窗口、设置、菜单内容、提示框及诊断文字，并保存在 `.state/preferences.json`。macOS 菜单栏靠近苹果图标的应用名称来自启动时的本地化资源，切换语言后需要重新打开应用更新，设置中会提示；不会因切换语言自动重启或打断定位会话。收藏名称和地图服务返回的地点名称保持原内容，不自动翻译。预览设置使用独立文件，自动界面检查使用内存设置，不修改真实偏好。

地图现在在应用所选语言环境下初始化。原生 MapKit 的公开接口不提供强制底图所有文字只用中文或英文的选项。应用语言可以控制本程序的控件和自定义选点标记，底图道路、地名和兴趣点的具体语言仍由 Apple 地图数据决定，可能包含原文或双语，不能保证严格单语言；中文启动的实测底图仍包含中文与英文对照。

## 已知限制

- 已通过一次 CLI 实机短时设置与恢复；仍仅启用 iOS 26 路径，原生界面实机流程待验证。
- 镜像下载有请求超时和取消能力，但没有完整文件下载百分比。
- 仅在瞬时连接阶段最多重试两次，退避 1 秒与 3 秒；不自动重试签名、挂载和位置写入。
- 尚未打包可分发的独立 Python 运行时，也未做 Developer ID 签名或公证。
- 本轮视图截图中底图未显示；可能涉及地图加载或图层截图，联网底图、地点搜索与国内外坐标一致性留待人工确认。
- 已验证一次手机定位生效与停止恢复；60 分钟保持、锁屏与拔插、连接性能指标仍待后续验证。
