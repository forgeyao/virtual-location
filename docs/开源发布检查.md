## 可重复检查

```sh
python3 scripts/check-publication.py
```

脚本使用 Git 自身的忽略规则取得文件清单。目录尚未初始化 Git 时，借助临时隔离的 Git 目录完成检查，检查脚本自身不创建项目 `.git/`、提交或远端仓库。有 Git 时同时检查已跟踪及未忽略文件，因此已被跟踪的 `.env` 等不会被忽略规则遮住。

检查包括常见私钥头、GitHub／AWS／部分 API 凭据格式、URL 内嵌凭据、个人主目录路径、常见设备唯一标识与硬件标识字面值；对于不应公开的文件类型、符号链接、未审查二进制及大文件会要求人工复核。输出仅包含路径、行号及问题类别，不回显匹配到的敏感值。生成的 PNG、PDF、ICNS 品牌资源另做个人路径检查，并结合绘图源审阅。

可生成仅包含通过检查的文件的源码归档：

```sh
python3 scripts/check-publication.py --archive dist/virtual-location-source.zip
```

归档从同次检查的内存快照生成，不读取检查后改动的文件；不包含文件扩展属性、Git 元数据、开发环境或设备缓存。归档中的顶层目录为 `virtual-location/`。归档已包含 GPL 许可全文与更新后的中英文 README。

## 结论与边界

当前待发布文件未检出上述高置信度凭据／设备标识模式；发现的个人绝对路径已从公开文档移除。忽略规则和发布文件边界通过合成敏感数据测试，实际清单仍应在每次提交前重新检查。

本次结果：62 个 Git 发布候选文件通过模式检查；28 项 Python 检查通过，其中包含忽略边界、已跟踪的忽略文件、合成凭据不回显、符号链接阻断及归档快照检查；20 个公开 Markdown 本地链接均指向发布清单中的实际文件。没有为文档更改重新执行实机测试。

初次检查在 Git 初始化前完成，没有已有提交历史；首次发布从当前通过检查的文件建立历史。若之后导入其他仓库历史，必须单独检查历史；如果凭据曾被公开，仅删除当前文件不能撤回泄露，应按凭据类型更换。模式扫描不保证发现所有秘密，也不覆盖压缩／加密内容、第三方服务的数据处理或依赖漏洞。
