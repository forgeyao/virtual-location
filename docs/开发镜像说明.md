# 开发镜像与 Apple 签名

开发者磁盘镜像（Developer Disk Image，DDI）提供 iPhone 调试所需的开发支持组件，本项目使用其中的开发者定位服务。它与刷机固件不同：挂载开发镜像不执行系统恢复，也不会清除用户数据。

iOS 26 的本项目候选路径使用 PersonalizedDMG。手机校验 Apple 针对设备签发的个性化凭据后，才接受加载开发组件。申请凭据涉及设备硬件标识（如 ECID、芯片和主板标识）与 nonce；nonce 用于限制凭据的重复利用。请求不包含目标经纬度、照片、通讯录或 Apple 账户密码。

镜像资源可缓存，设备重启或开发支持环境变化后，可能需要重新挂载或取得新凭据。程序将读取设备状态再决定需要执行的步骤，不在每次修改位置时重复准备镜像。

当前依赖的默认签名实现使用 HTTP 且关闭 TLS 校验。项目的隔离适配器将请求发送到 `https://gs.apple.com/TSS/controller?action=2`，保持证书验证并设置连接和读取超时，不修改系统配置或依赖安装文件。

签名适配器优先使用显式指定的 `REQUESTS_CA_BUNDLE` 或 `CURL_CA_BUNDLE`，否则使用 Python 平台默认 CA 文件；无可用平台文件时继续使用 Requests 默认校验。2026 年 11 月 7 日实机验证发现 Requests 的 certifi 证书库无法验证当时 Apple 签名服务的证书链，而本机 Python 平台 CA 可以；已修复默认选择并验证 HTTPS 连接，不通过关闭验证绕过证书错误。

首次申请签名需要明确允许；命令行通过 `--allow-apple-signing` 表达此选择。该参数不修改系统设置，也不授权其他外部服务。

公开实现依据：

- [pymobiledevice3 开发镜像实现](https://github.com/doronz88/pymobiledevice3/blob/master/pymobiledevice3/services/mobile_image_mounter.py)
- [pymobiledevice3 TSS 实现](https://github.com/doronz88/pymobiledevice3/blob/master/pymobiledevice3/restore/tss.py)

正式实现固定使用 `pymobiledevice3==11.49.0`；阅读时应以该安装版本的源码为准，主分支可能变化。
